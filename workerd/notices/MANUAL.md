# Texts added by hand

This file belongs to the notices bundle of `workerd-closed-graph-2026-08-11-linux-x64`
(Takoserver `docs/release-assets.md`, "The notices bundle", step 4). It was
written on 2026-10-11 from the build state of the pinned binary.

Step 3 copies the license, copying and notice files of every repository that
the build fetched. It found none for the seven repositories in part 1, and
for the 30 Rust crates in part 2 it could only record the `license` field of
the package, because those packages ship no license file. For each entry this
file says where its version is pinned, where the text below was taken from,
and the text's SHA-256. Part 3 lists what could not be determined exactly.

Texts fetched from GitHub were read through the GitHub contents API at the
stated commit; each matched the git blob id the API reported for that path.
